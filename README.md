## Reproduce the analysis

1. Use Python 3.10+.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. From the repository root, run:
   ```bash
   python analysis/run_analysis.py
   ```
4. Review the generated tables in `outputs/` and charts in `assets/charts/`.

The SQL files are written as example queries. Load the CSV files into a SQL database and use the matching table names in the comments.

## View as a GitHub Pages site

1. Create a public GitHub repository named `enosh-tandi-portfolio`.
2. Upload the contents of this repository to the root of the new repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. GitHub will show the published site URL in the Pages section.

For a GitHub profile README, create another public repository whose name exactly matches your GitHub username, then paste the contents of [`GITHUB_PROFILE_README.md`](GITHUB_PROFILE_README.md) into that repository's `README.md`.
